# Квиз ЦАД — Таблица результатов

Сайт для отображения результатов команд в квизе в реальном времени.

## 📍 О событии

- **Место:** СПБ ГКУ ЦАД, ул. Черняховского, 17
- **Дата:** 27 февраля 2026 г.
- **Повод:** К 23 Февраля и 8 Марта

## ✨ Возможности

- 🏆 **Таблица лидеров** — общий счёт всех команд
- 📊 **Результаты по раундам** — детализация по 7 раундам
- ⭐ **Раунд «Вабанк»** — специальный вывод со столбцом ставок
- 📈 **Визуализация** — графики прогресса и распределения баллов
- 🔄 **Автообновление** — данные обновляются каждые 5 секунд
- 📱 **Адаптивность** — работает на мобильных и ПК

## 🗂️ Структура данных в Google Sheets

### Лист с результатами (основной)

| Столбец | Поле | Описание |
|---------|------|----------|
| A | Команда | Название команды |
| B | Номер раунда | 1-6 |
| C | Название раунда | Название раунда |
| D | Номер вопроса в раунде | Номер вопроса |
| E | Текст вопроса | (резервное поле) |
| F | Полученные баллы | Баллы за вопрос |

### Лист «вопросы»

| Столбец | Поле | Описание |
|---------|------|----------|
| A | Номер раунда | 1-6 |
| B | Номер вопроса | Номер вопроса в раунде |
| C | Описание вопроса | Текст вопроса для отображения |

### Лист «команды»

| Столбец | Поле | Описание |
|---------|------|----------|
| A | Команда | Список всех команд-участниц (по одной в строке) |

**Важно:** Все команды должны быть указаны в листе «команды» для корректного отображения на графиках и в таблице лидеров, даже если у них ещё нет результатов.

## ⚙️ Настройка

Для подключения к вашей таблице Google Sheets измените параметры в `js/quiz.js`:

```javascript
const CONFIG = {
    spreadsheetId: 'YOUR_SPREADSHEET_ID',
    range: 'A1:Z1000',
    apiKey: 'YOUR_API_KEY',
    autoRefreshInterval: 5000,
};
```
